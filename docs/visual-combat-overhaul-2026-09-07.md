# Visual, Shooting & Content Overhaul — 7 Sep 2026

Full change log for the overhaul pass driven by playtest feedback: shooting feel,
crosshair visibility, new era-correct weapons, flag heraldry, level density,
combat VFX, UI layering, and a logic bug audit with regression tests.

## Shooting mechanics

- **M70 is fully automatic** — `is_automatic = true` (fire_rate 0.13); hold LMB to
  keep firing. Škorpion stays automatic; pistol/shotgun/M48/M76 stay semi-auto.
- **Spread bloom** — sustained fire accumulates `current_bloom`
  (`bloom_per_shot`/`max_bloom` on `WeaponResource`), recovering at
  `BLOOM_RECOVERY_RATE`/s when the trigger is released; switching weapons resets
  it. Bloom feeds both projectile spread and the crosshair ring via the
  `bloom_changed` signal.
- **Pool pre-check** — `fire()` asks `Player.count_free_projectiles()` before
  spending ammo; a short pool trims shotgun pellets instead of burning ammo on
  shots that never spawn.
- **OS cursor** hides during `PLAYING` (`GameManager._apply_mouse_mode()`) so the
  custom crosshair owns the screen.

- `PaperOverlay` moved to `CanvasLayer 0` so HUD/menus sit above the grain.
- HUD bottom bar re-anchored via an expanding spacer; ammo frame realigned with
  the ammo label.
- **Results screen fix (7 Sep):** `ResultsScreen` is a `CanvasLayer` (layer 2) so

  detail/debrief labels are authored in-scene with ink-brown colors.

## Bug audit fixes

| Bug | Fix |
|---|---|
| Hit flash wiped faction tint ("pink blob") | `EnemyBase` stores `base_modulate` meta; `EnemyHitFeedback` tweens back to it |
| Initial checkpoint saved before difficulty kit | Kit application re-saves the checkpoint so respawns keep kit bonuses |
| M2 reinforcements tripped instantly on Easy (or late on Hard) | Bunker `start_health` snapshot deferred until after difficulty scaling; outright destruction also trips reinforcements |
| Enemies reset to PATROL the instant the player left detection radius | 2.5 s pursuit grace (`_on_pursuit_timeout`) before disengaging |
| `ScoreManager.get_accuracy()` truncated floats via `mini()` | `minf()` |
| Staggered spawns / wave / cooldown timers firing on freed nodes | `is_instance_valid` guards in MissionController, M3/M5 controllers, Rifleman, MachineGunner, Sniper, Mortar, Tank, APC, CombatVfx |
| Ammo crate silent while pistol held | `add_ammo()` redirects to the best carried non-pistol weapon |
| Shotgun pellets lost to pool exhaustion | Pre-check trims `last_pellet_count` to available pool |
| Double casing ejection | `CombatVfx.vfx_muzzle_flash(..., eject_casing)` flag; player path passes `false` |
